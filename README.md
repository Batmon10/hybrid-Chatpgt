# Offline ChatGPT with Custom Data & Remote Access

This project lets you run an open-source LLM like Mistral locally using [Ollama](https://ollama.com), feed it your own documents using [LlamaIndex](https://llamaindex.ai), and access it remotely via a Flask API secured using [Tailscale](https://tailscale.com).

Created: 2025-05-01

## Features
- Fully offline GPT model (no internet required)
- Retrieval-Augmented Generation (RAG) with your PDFs or text files
- Remote access over secure Tailscale VPN
